# Athidi Foods — Static Website

A responsive, static HTML/CSS website based on the Athidi Foods promotional poster.

## Files
- `index.html` — website content
- `style.css` — responsive styling
- `assets/athidi-food.jpeg` — supplied promotional image

## Contact actions
The WhatsApp button opens a chat with **+91 96186 34908** and includes a prefilled subscription enquiry.
The Call Now button uses a `tel:` link for direct calling on supported devices.

## Free hosting
This is a static website, so it can be hosted for free on:
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

No backend or database is required for the current version.

## Important
The site intentionally says the website is "Launching Soon" and explains that online subscription management and other features are coming later.
